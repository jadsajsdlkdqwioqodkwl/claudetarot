# Instrucciones del Project (lo único que va en claude.ai)

Pegar en claude.ai → Project → Instrucciones, reemplazando todo lo anterior.
El Project necesita el conector de Google Sheets (y Google Drive para leer el
brief). Las instrucciones de verdad viven en la pestaña **Instrucciones** de
la hoja; Claude Code las edita con cada feedback (copia en
`creativos/instrucciones.md`).
